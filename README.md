# CE – Chart Corrector

CE は、React と Node.js を用いて構築した「チャート補正・タグ管理ツール」です。  
データの検索、タグ付け、編集、フィルタリングを効率化し、業務で扱う大量データの整理を支援します。

---

## 🚀 主な機能

### ✔ タグ管理
- タグの新規作成  
- タグ名の編集  
- タグの削除  
- 選択済みタグの一覧表示  
- AND / OR 条件によるタグ検索

### ✔ データ検索
- キーワード検索  
- タグ条件検索  
- 複数条件の組み合わせフィルタ  
- 高速な検索ロジック（useDbFilter）

### ✔ UI / UX
- 左ペインでの直感的な操作  
- 編集ダイアログ（EditDataDialog / CreateTagDialog）  
- 選択式タグ UI（クリックで選択・編集）

---
